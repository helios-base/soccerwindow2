# palette.txt -- the colors of the icons
#
# Each line has three fields: ROLE LIGHT DARK
#   ROLE   the name of the role of the color
#   LIGHT  the color for the light color scheme (used in the SVG files)
#   DARK   the color for the dark color scheme
# The colors are written as "#rrggbb" in lower case.
#
# The SVG files in svg/ must use only the LIGHT colors of this table.
# generate.sh replaces the LIGHT colors with the DARK colors to create the
# icons for the dark color scheme. See docs/icons.md.
